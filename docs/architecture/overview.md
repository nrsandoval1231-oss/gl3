# Architecture and evidence boundaries

GridLens follows the [PRD](../product/PRD.md): one FastAPI backend, separate Python worker, React/TypeScript web app, and PostgreSQL for durable jobs and product history. Source-specific retrieval and parsing belong in ingestion adapters; identity, evidence interpretation, qualification, and deterministic calculations belong in backend domain services; the web layer presents server-owned project, need, evidence, buyer, and action state. The current implementation also contains versioned attributed need facts and decisions that trigger deterministic reassessment, separate from workflow-status events. Current intelligence paths include `intelligence/commercial_evaluation.py` and `intelligence/autonomous_research.py` importing API projection code from `api/app.py`; this coupling is documented for the Stage 6 targeted extraction, not presented as an idealized current boundary. API response types derive from the OpenAPI contract. Folder names and historical code descriptions do not establish implemented capability.

Evidence must retain source identity, retrieval/publication/event dates where available, hashes and permitted excerpts, extraction location, and claim attribution. Project identity, each power activity, its evidence, tier, schedule, supply assessment, and buying path remain distinct. Unknown or conflicting inputs stay visible. Similar names, source outages, facility capacity, generic contacts, status labels, or a missing utility response cannot establish a power gap or Lead. Deterministic gates own tier decisions; model output or user notes do not bypass them.

Authentication and writes require server-side authorization. Trusted proxy configuration must be explicit. Durable jobs require bounded retries, leases/fencing, idempotency, and visible partial/failure outcomes. Operations require measured source freshness, scheduler/worker health, alert state, cost/backlog, and recoverable backup evidence; deployment preparation is not deployment.

This describes boundaries, not a claim that the system is running now.
