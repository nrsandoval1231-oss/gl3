## First three small PR slices

1. **Inventory mapping (no schema change):** document existing evidence/identity fields and relation paths used by one Oil & Gas cohort; identify exact reused and missing fields with tests as evidence.
2. **Claim contract and fixtures:** introduce a pure typed representation and deterministic validation for drive type, electrical basis, project/activity binding, unknown/conflict and provenance; fixture-only, not wired into scoring/publication.
3. **Additive persistence and shadow read:** add only confirmed missing fields/table with migration; persist/recompute on an isolated fixture path; compare output without changing existing lead, ranking or UI projection.

Each slice should have one file/schema ownership boundary, a focused review, and exact regression evidence. Stop after slice 1 if the current schema already covers the proposed contract or if source evidence is insufficient; do not add abstractions merely to conform to the roadmap.

## Shared release and rollback gates

- Keep existing PostgreSQL, Python worker, adapters, FastAPI and React architecture unless measured limits justify a change.
- Keep migrations additive and backward-compatible. Validate against a disposable database and isolated restore; never run production migration/replay as part of ordinary implementation.
- Preserve source provenance, evidence history, source health, suppression/privacy, idempotency, fencing, retries, cost accounting and current qualification semantics.
- Keep model/provider use optional and bounded; no paid-provider activation without separate authorization. A model inference cannot silently become a fact or qualification decision.
- Use current repository CI and `scripts/check.ps1`; run applicable backend, migration, frontend, browser and docs checks for the touched boundary. Record exact commands/outcomes and unavailable checks. Live production state remains a separate verification boundary.
- Roll back by disabling the new task/projection/model version and returning consumers to the last accepted version. Do not delete retained evidence to roll back.

## Deferred until evidence supports it

New graph databases, orchestration frameworks, full recrawls, multi-agent hierarchies, broad autonomous code mutation, and additional verticals beyond Oil & Gas then Data Centers. Reconsider only with a measured need, ownership boundary, cost model and reversible implementation plan.
