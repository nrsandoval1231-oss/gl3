### Retrieval and pagination observations

The packet snapshot directly fetched Taylor NewsFlash roots for category 30 and 31, three category-31 detail records, the archive root and Mustang archive detail. Root/detail/archive requests returned HTTP 200 `text/html`; response sizes and SHA-256 are in the retrieval ledger. The category-30 page exposed eight entries in its rendered response; category 31 exposed three. Entries link numeric article IDs. The archive item preserves the `WITHDRAWN` label. A direct request to an inferred `/Home/Items?...` lazy-loading route did not return useful item content in this probe; it is explicitly **not** treated as a validated pagination API. The live adapter must request the rendered category pages, follow only observed links, and fail visibly if it cannot prove that the declared window is complete. Archive enumeration and pagination remain unproven.

Round Rock PUD register direct request returned HTTP 200 `text/html`, 356,859 bytes in the retained snapshot; the project page also returned 200. The register is a full long list (677 lines in browser text); no pagination was apparent in the rendered page. Approval date and PUD number are inspectable, but the current entry is a curated register and cannot establish original filing or first-publication time.

No source response supplied stable HTTP `Last-Modified`/ETag semantics that this packet validates; use retrieval time, original published/effective dates when explicitly shown, canonical URL/case IDs, and content hashes. Poll cadence, archival retention, and upstream correction latency are not published. Request cost is $0 for public GET; network/compute cost was not measured. No broad legal/access policy conclusion is made from successful requests; restrict collection to public HTML and short factual excerpts with attribution.
