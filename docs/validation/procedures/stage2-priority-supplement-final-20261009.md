This maximum-four-record set is separate from the unchanged 36-record hash/strata quality sample and is excluded from all of that sample's metric denominators. Selection uses the same full authentic 6,448-observation pool. The private freeze receipt binds the pool, the fixed-sample procedure, this file, and the selected IDs before supplemental source judgments or payload checks.

First exclude the fixed 36 selected IDs. A row is eligible only when the source activity fields (`title`, `description`, `work`, or `proposed land use`) explicitly identify one of these ordered scope classes: (1) data-center/data-centre, (2) commissioning or temporary service/power/generator installation, or (3) new construction / construction of or for. Organization names and other non-activity fields cannot satisfy scope. A source-listed organization and its stated role are required: Austin contractor company/trade or applicant organization, or Dallas LP Business Name/Contact Type. Preserve the source role verbatim; it does not establish owner, prime contractor, buyer, utility, power requirement, or authority. Routes without these fields do not qualify under this method.

Sort by scope class in the order above; within each class sort by official source event date descending, then UTF-8 bytewise source ID and stable record ID ascending. The official date is the source row event date, not a publication time. Select the first four, or all eligible rows when fewer than four exist. Do not pad, substitute, or change the fixed sample. The first generic-construction pass is retained as dated exploratory history and is not this final priority supplement.

For each final selected row, compare at most one exact source-record payload using the existing official route, native bounded client, and parser. Deduplicate only when multiple selected IDs share one already captured source artifact. Keep raw payloads privately with request/response-body hashes. No new ingestion jobs, database writes, providers, or source breadth. If the client does not expose HTTP status, report it as UNKNOWN. A named permit applicant or electrical/general contractor does not prove buyer authority or temporary demand. Preserve UNKNOWNs and issue no pursuit recommendation absent source-backed power need and a suitable buying path.
