# Massachusetts CCC cultivation application source

GridLens reads the Massachusetts Cannabis Control Commission's public applications snapshot at [`l_applications_all_details.json`](https://masscannabiscontrol.com/resource/l_applications_all_details.json). The CCC publishes its source descriptions in the [Open Data Catalog](https://masscannabiscontrol.com/open-data/data-catalog/). The adapter downloads one whole JSON snapshot (no pagination), with a 10 MB response bound, a 2,500-row bound, a 30-day snapshot freshness limit, and a 30-second retrieval deadline. The public GET needs no credentials; a descriptive `User-Agent` is sent because an unlabelled default HTTPX request returned 403 in this environment while the identified request returned 200.

The adapter filters the exact `LICENSE_TYPE == "Marijuana Cultivator"` value. On 2026-10-01, two successful identical fetches each returned 1,989 source rows and 452 cultivator rows; the body SHA-256 was `a46b79846534783ab78121e4a2acfb6dc30c10207bfc7d7af153efa9c8d637f3`. The export's `CCCLastUpdated` was 2026-09-22. The 452 cultivator records comprised 398 `APPROVED`, 2 `PENDING`, and 52 `REOPENED` applications. These counts describe that snapshot, not complete statewide coverage.

Each source observation uses `APPLICATION_NUMBER` as stable identity, falling back to `LICENSE_NUMBER` only when the application number is absent. A correction to submission date or status changes the semantic row hash while preserving the observation identity. The whole-file hash is retained separately as snapshot provenance. The row hash covers only explicitly whitelisted business, site, application, and lifecycle facts; it excludes EIN, mailing address, personal contacts, financial/background fields, and other unrelated CCC columns. Public `BUSINESS_EMAIL` and `BUSINESS_PHONE` are retained under explicit applicant-business-contact labels and do not imply a buyer or decision-maker.

Application event dates (`SUBMITTED_DATE`) remain distinct from `ORIGINAL_SUBMITTED_DATE`, application creation/approval/denial, snapshot date, and license/operations lifecycle dates. When a later submitted date follows the original filing date, the event is labeled `Application resubmitted date`. Only pending or reopened records with a source event no older than 120 days, an applicant organization, a complete physical Massachusetts establishment address, and no evidence of issued/commenced/closed licensing can become ordinary discovery Signals. Stale, approved, missing-site, and lifecycle-conflicted rows remain retained source observations without a new-facility Signal.

The example source event is Rhythm of Life Cannabis LLC, application `MCN284034` / license `MC284034`, listed as `PENDING` / `IN PROCESS`, with submitted date 2026-09-03, original submitted date 2026-06-15, and establishment at 616 Douglas Street, Uxbridge, MA 01569. The event supports investigation of an application only. It does not establish construction, current work, operation start, electricity load, rental demand, a buyer, ownership, or buying authority. No growing area, canopy, license tier, or class is translated into MW. Unknown power need and authority remain explicit.

The CCC catalog warns that published dataset contents are self-reported and are not guaranteed complete, accurate, or timely. A recent application is therefore a bounded public lead, not proof of project execution. Source failures, malformed or stale snapshots, duplicate application IDs, or unexpected schema prevent the snapshot from replacing prior retained evidence.
