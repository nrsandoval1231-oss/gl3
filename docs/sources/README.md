# Sources and coverage

`coverage.md` tracks validated source feeds, last successful run, geography, industry, source family, and known gaps. `onboarding.md` describes real retrieval, parsing, persistence, replay, and rights checks for a new feed. A planned source is never counted as active.

Read the [ingestion strategy](ingestion-strategy.md) before implementing source collection. It defines discovery, targeted monitoring, reconciliation, source readiness, and historical/live validation. The immediate priority is a validated coverage matrix and a complete ingestion path.
