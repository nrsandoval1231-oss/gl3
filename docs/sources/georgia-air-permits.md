# Georgia EPD Draft Title V source

> GL3-018 supersedes standalone news/planning Signal admission and expands the existing Chicago/Georgia routes. See [current admission and acquisition behavior](gl3-018-admission-and-acquisition.md). Historical validation below is not a new live check.

Checked 2026-09-27 UTC. The configured source is the official [Georgia EPD Draft Title V permits and amendments listing](https://epd.georgia.gov/draft-title-v-permitsamendments-other-draft-permits). Its page embeds a public Knack app (`5582edf87a0f92370d4ae1f9`), scene `scene_1`, view `view_1`. Retrieval uses the observed public GET endpoints for fixed app metadata and that fixed records view. The adapter does not accept URLs, app IDs, field maps, or page controls from returned rows.

The observed snapshot returned 18 of 18 rows. Public-comment deadlines ranged from 2026-09-28 to 2026-10-26. These dates describe comment windows only. The source does not provide a publication timestamp, so the evidence publication date remains unknown. A separately source-stated application date or received date is retained only as a labeled event date; the record's retrieval timestamp is also preserved independently. A closed comment window does not by itself show that the listed draft has been withdrawn, completed, or supplied.

For each record, the adapter retains the Knack record ID, source application number, facility, site, deadline, listing citation, official linked-document URLs, PDF hashes, and up to eight selected page excerpts (maximum 16,000 excerpt characters per PDF) with page citations. It fetches narrative and draft-permit PDFs (36 documents for the observed 18 rows), validating the listed facility/application and site against extracted PDF text. Eight public-notice URLs in the inspected snapshot are retained as explicitly unextracted references; this avoids an identity mismatch on notices with inconsistent facility spellings while preserving the source trail. Required narrative/draft attachments, rows, or pages that cannot be validated fail the run visibly; it does not report a partial snapshot as complete. Bounds are 5 list pages/500 records, 2 MB per listing response, 30 MB total bytes, 50 PDFs, 4 MB/PDF, 200 pages/PDF, and 5,000 PDF pages/run. Requests time out and redirects are disabled.

The adapter derives a short current-scope excerpt from the narrative's stated application purpose plus explicit prospective site-work clauses in the opening background; each retained clause carries its PDF page. Prior-permit inventories and later historical equipment descriptions do not qualify a current filing by themselves. Specific named-site facility construction/expansion, physical equipment changes, partial utility/campus capacity statements, and proposed standby generation can become discovery Signals. A Signal is not a confirmed gap or sales lead. Campus, service, and equipment quantities remain reported source facts; a possible construction/commissioning bridge-power inquiry is explicitly an inference and never a calculated rental MW amount. Missing energization date, available supply, buyer, rental quantity, and project status remain unknown. Generic policy-only entries and routine renewals without relevant new activity stay in evidence/history. An explicit application withdrawal closes that application; generic statements that a facility is operational do not cancel a separately proposed phase or expansion.

Observed current named listings included QTS ATL3, QTS Fayetteville I, TADG facilities, Graphic Packaging International's Perry Carton Facility and Bonnell Aluminum. These names document source access only; their appearance in the source list is not an assertion that each qualifies as a current power opportunity. The Bonnell Aluminum linked draft is 76 pages and 920,088 bytes, so the per-document cap supports that demonstrated valid size. The feed is Georgia Draft Title V only. It is not a complete list of air applications, issued permits, amendments, all ongoing project activity, or a national discovery source. Some listed applications may be renewals; evidence must be assessed per filing.

Raw bounded GET inspection metadata and row/document link receipts are stored in ignored `.artifacts/GL3-011/ga-source-get-evidence.json`; they are probe artifacts and are not application observations. Live database job/replay proof and application migration status are controller-owned and are not claimed here.
