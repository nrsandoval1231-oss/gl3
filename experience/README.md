# experience/

Persistent engineering knowledge for GL3. Curated, not a log: add an entry only when it will save a future engineer real time. See `.claude/skills/experience-driven-development/SKILL.md`.

| File | Holds |
|---|---|
| architecture.md | Current structure notes that are not in `docs/architecture/` |
| decisions.md | Decisions with rationale |
| patterns.md | Proven reusable approaches |
| mistakes.md | Recurring or costly failures and prevention |
| retrospectives.md | Initiative reviews |
| benchmarks.md | Measured results with commands |
| agent-performance.md | Evidence on how agents performed |
| proposed-improvements.md | Proposed policy/config changes awaiting review |
