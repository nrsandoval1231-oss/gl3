# Documentation index

`product/` contains the canonical PRD and lifecycle strategy. `design/` contains owner-approved UI/brand references. `architecture/` states implementation boundaries. `sources/` records source coverage and limitations. `operations/` links current operational truth and future procedures. `delivery/` tracks acceptance gates. `validation/` retains dated, candidate-bound evidence.

For current status, start at [delivery milestones](delivery/milestones.md). [`.agent/CURRENT_STATE.md`](../.agent/CURRENT_STATE.md) is the short checkpoint. Dated historical reports remain historical; the archive index is [here](../.agent/archive/STAGE1-20261009/ARCHIVE-INDEX.md).
