# Agent rules — current authority

Read [AGENTS.md](../AGENTS.md) and the [Autonomous Intelligence Canon](../docs/product/AUTONOMOUS_INTELLIGENCE_CANON.md) first. They supersede contradictory historical PRD, design, workflow, harness and agent directions.

Use actually available supported OpenAI models: Sol 6.1/high coordination, three to six Luna 6/low builders and Astra 6/high independent review. User-authorized parallel work uses isolated worktrees and explicit non-overlapping file ownership; coordinate contract changes before integration. Never claim an assignment, test or review that did not run. The controller owns integration and final reruns.

Remove obsolete manual product behavior through routes, clients, components, tests and documentation; preserve immutable evidence, historical records, deterministic rules, regional constraints, auth and brand. Keep secrets and raw private artifacts outside Git. No destructive schema/data changes. Paid providers, deployment and production writes require applicable authorization and validated safeguards; ordinary scoped reversible implementation proceeds under the current owner request.

Bind test/review outcomes to the actual candidate. Changed code requires relevant revalidation. Report unknown timings, cost, coverage, provider health and deployment state as UNKNOWN. Preserve failed-run evidence and distinguish fixture checks, retained-data replay, real-source execution and production operation.
